# ⚡ Zenith DSL v1.0.0 — Release Notes

> **The Next-Gen Web DSL for Java & Spring Boot**  
> *Eliminate the 9-file ceremony of enterprise Java. Declare backend models, relationships, security, and endpoints in a single `.zen` file and transpile to production-ready Spring Boot 3 in milliseconds.*

---

## 🌟 Highlights & What's New

### 1. 🚀 Zero-Ceremony Full Stack Backend Generation
Replace ~350 lines across 9 boilerplate files (`Entity`, `CreateDTO`, `UpdateDTO`, `ResponseDTO`, `Repository`, `Mapper`, `Service`, `ServiceImpl`, `Controller`) with **15–20 lines of clean `.zen` code**:
* **Jakarta Persistence (`@Entity`)**: Automated table mapping, identity primary keys, lifecycle audit hooks (`@PrePersist`, `@PreUpdate`), and relation foreign keys.
* **Java 17 Records**: Request and response DTOs with automated Jakarta validation annotations (`@NotBlank`, `@Size`, `@Positive`, `@Min`, `@Max`, `@Email`).
* **High-Performance Mappers**: Zero-dependency `@Component` mappers converting entities to DTO records.
* **Spring Data JPA Repositories**: Derived query methods for unique fields and case-insensitive keyword searches.
* **Service Layer**: `@Service` with declarative transaction management (`@Transactional(readOnly = true)`).
* **REST Controllers**: Full RESTful endpoints with pagination (`?page=0&size=20`), dynamic sorting, and multi-field search.
* **Global Error Handling**: `@RestControllerAdvice` converting validation failures into clean, structured JSON field error maps.

---

### 2. 🔒 Enterprise Security & JWT Authentication (Phase 2)
* Turn on authentication with one flag: `auth: jwt`.
* **Automatic Password Shielding**: Any field with `@password` is hashed using `BCryptPasswordEncoder` and automatically stripped from Response DTOs to prevent credential leaks.
* **Role-Based Access Control**: `@role` attributes map directly to Spring Security `GrantedAuthority` (`ROLE_ADMIN`, `ROLE_CUSTOMER`).
* **Complete Security Pipeline**: Generates `SecurityConfig.java` (stateless session, CORS, CSRF disabled), `JwtService.java`, `JwtAuthenticationFilter.java`, `CustomUserDetailsService.java`, and `AuthController.java` with `/api/v1/auth/login` and `/api/v1/auth/register`.

---

### 3. 📖 OpenAPI 3 & Interactive Swagger UI (Phase 2)
* Turn on with `swagger: true` (default).
* Auto-configures `springdoc-openapi-starter-webmvc-ui` in `pom.xml`.
* Generates `OpenApiConfig.java` pre-configured with Bearer JWT SecurityScheme.
* Every controller and route is auto-annotated with `@Tag` and `@Operation(summary = "...")`.
* Access interactive docs at `http://localhost:8080/swagger-ui.html`.

---

### 4. 🗄️ Database Migrations with Flyway (Phase 2)
* Automated DDL generation targeting PostgreSQL / H2: `src/main/resources/db/migration/V1__initial_schema.sql`.
* Accurately converts types to SQL primitives (`BIGINT GENERATED BY DEFAULT AS IDENTITY`, `VARCHAR`, `NUMERIC(p,s)`, `TIMESTAMP`, `BOOLEAN`, `TEXT`).
* Builds foreign key constraints and creates database indexes on foreign keys and search columns.

---

### 5. 🧠 Declarative Business Logic & Guards (Phase 3)
Custom endpoints can now execute logic without writing boilerplate Java:
```zen
post "/{id}/ship" -> OrderResponse {
    description: "Marks an order as shipped"
    guard: status == OrderStatus.PAID, "Only paid orders can be shipped"
    action: {
        status = OrderStatus.SHIPPED
    }
}
```
* **`guard:`**: Enforces pre-conditions, throwing descriptive 400 Bad Request errors if conditions are violated.
* **`action:`**: Performs entity state mutations and automatically saves via the repository.

---

### 6. 🛠️ CLI Watch Mode & VS Code Extension (Phase 4)
* **`zenith watch <file.zen> -o <dir>`**: Hot-reload daemon that auto-recompiles your schema in **< 150ms** whenever you save.
* **VS Code Extension** (`editors/vscode/`):
  * Custom TextMate grammar with syntax highlighting for keywords, decorators, types, and operators.
  * Code snippets for `config`, `model`, `enum`, and `endpoint`.
  * Auto-closing pairs for `{}` `[]` `()` `""`.

### 7. 🌐 Full-Stack TypeScript SDK & Docker Infrastructure (Phase 5)
* **TypeScript Client SDK (`sdk/typescript/`)**:
  * Auto-generates strongly-typed TypeScript interfaces for models, request DTOs, and query parameters.
  * Zero-dependency `ZenithClient` using native `fetch` with automatic JWT Bearer token injection.
  * Ready-to-use **React Query hooks** (`useProductList()`, `useProduct()`, `useCreateProduct()`, `useDeleteProduct()`) with automatic cache invalidation.
* **Instant Dockerization**:
  * Multi-stage `Dockerfile` (`maven:3.9` build + `eclipse-temurin:17-jre-alpine` runtime).
  * `docker-compose.yml` pre-configured with PostgreSQL / MySQL healthchecks and persistent storage.

## 🏃 Quick Start

```bash
# 1. Inspect schema metadata:
zenith inspect examples/ecommerce.zen

# 2. Watch & hot-reload:
zenith watch examples/ecommerce.zen -o backend

# 3. Compile:
zenith build examples/ecommerce.zen -o backend

# 4. Run Spring Boot:
cd backend
mvn spring-boot:run
```
