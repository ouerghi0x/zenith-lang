# Zenith DSL Distribution Artifacts

The standalone binary release and installation assets are located here:

* `zenith.jar`: Executable fat JAR
* `zenith.bat`: Windows Command Prompt launcher
* `zenith.ps1`: Windows PowerShell launcher
* `zenith`: Linux / macOS bash launcher

## One-Line Install Script (Coming Soon)
* Windows (PowerShell): `irm https://get.zenith-lang.dev | iex`
* Linux / macOS (curl): `curl -fsSL https://get.zenith-lang.dev | bash`
