One File. Infinite Power.

Look at how clean your backend definitions become. No boilerplate, no tedious annotations.

config {
    app: "ShopSphere"
    package: "com.shopsphere.backend"
    basePath: "/api/v1"
    port: 8080
    database: postgres
    auth: jwt
}

model Product {
    id: Long @id @auto
    sku: String(length = 32) @unique
    title: String(min = 3, max = 150)
    price: Decimal(precision = 12, scale = 2) @positive
    stock: Int @min(0) = 0
    status: ProductStatus = ACTIVE
    createdAt: DateTime @autoNow

    relations {
        category: Category @relation(manyToOne)
    }

    endpoints {
        crud {
            paginate: true
            search: [title, sku]
            filter: [status]
        }

        post "/{id}/archive" -> ProductResponse {
            guard: status != ProductStatus.ARCHIVED, "Already archived"
            action: {
                status = ProductStatus.ARCHIVED,
                stock = 0
            }
        }
    }
}
import { createClient } from '@shopsphere/sdk';

// Fully typed client with zero external dependencies
const api = createClient({
  baseUrl: 'http://localhost:8080',
  getToken: () => localStorage.getItem('jwt_token')
});

// 1. Strongly-typed query with search and pagination
const page = await api.products.list({
  page: 0,
  size: 20,
  search: 'sneakers',
  status: 'ACTIVE'
});

// 2. Typed creation payload
const product = await api.products.create({
  sku: 'SNK-9001',
  title: 'Aero Velocity Sneakers',
  price: 129.99,
  stock: 50
});

// 3. Auto-generated custom endpoint action
await api.products.postArchive(product.id);
import React from 'react';
import { useProductList, useCreateProduct } from '@shopsphere/sdk/react-query';

export function ProductGrid() {
  // Instant data hook with caching and loading state
  const { data, isLoading } = useProductList(api, { page: 0, size: 12 });
  
  // Mutation hook with auto query invalidation
  const createMutation = useCreateProduct(api);

  if (isLoading) return <div>Loading catalog...</div>;

  return (
    <div className="grid">
      {data?.content.map(p => (
        <div key={p.id} className="card">
          <h3>{p.title}</h3>
          <p>${p.price.toFixed(2)}</p>
        </div>
      ))}
    </div>
  );
}

Java Ceremony vs. Zenith

Why write 9 files of boilerplate when you can describe intent in one?

Traditional Java / Spring Boot

9 Files • ~350 Lines per Model

  • ❌ Entity.java with 8+ Hibernate annotations
  • ❌ CreateRequest.java record with validation
  • ❌ UpdateRequest.java record with partial keys
  • ❌ Response.java duplicate record
  • ❌ Mapper.java hand-wired converters
  • ❌ Repository.java interfaces with queries
  • ❌ Service.java interface
  • ❌ ServiceImpl.java tedious paging & mapping
  • ❌ Controller.java verbose routing boilerplate
Zenith DSL Solution

1 Schema • 18 Lines • < 200ms Build

  • ⚡ 1 clean file describes the entire domain
  • ⚡ Spring Security 6 + JWT auto-configured
  • ⚡ OpenAPI 3 / Swagger UI auto-documented
  • ⚡ Flyway SQL Migrations generated automatically
  • ⚡ Declarative Business Logic with guard: blocks
  • ⚡ TypeScript Client & React Query included
  • ⚡ Multi-stage Dockerfile ready to deploy
  • ⚡ Sub-150ms Watch Mode hot reload

Built for Real Enterprise Demands

Not a toy DSL. Zenith generates battle-tested, idiomatic Spring Boot 3 code you'd proudly push to production.

🛡️

Spring Security 6 & JWT

Activate with auth: jwt. Passwords annotated with @password are BCrypt hashed and stripped from response records. Roles integrate with Spring Security authorities.

📚

Swagger UI & OpenAPI 3

Every controller, route, and DTO is pre-annotated with @Tag and @Operation. Access interactive API documentation instantly on /swagger-ui.html.

🗄️

Flyway Database Migrations

Generates idempotent V1__initial_schema.sql scripts with identity auto-increment, correct SQL data types, foreign keys, and indexes.

🧠

Guards & Action Blocks

Declare business conditions directly inside endpoints. Zenith transpiles guard: conditions into structured 400 Bad Request error handlers and executes mutations cleanly.

🔥

Lightning Hot Reload

Run zenith watch schema.zen. In less than 150ms, your entire Java architecture is regenerated and kept synchronized with your ideas.

💻

VS Code Extension

Full language tooling with rich syntax highlighting, auto-closing braces, and snippets for models, enums, and endpoints.

Install in Seconds

Get the Zenith CLI running on your machine with your preferred tool.

Install via the official Zenith Scoop bucket:

scoop bucket add zenith https://github.com/ouerghi0x/zenith-bucket
scoop install zenith

Download the standalone zenith.jar from GitHub Releases and run with Java 17+:

curl -LO https://github.com/ouerghi0x/zenith-lang/releases/download/v1.0.0/zenith.jar
java -jar zenith.jar build schema.zen -o my-backend

Install the .vsix package directly into VS Code or VSCodium:

code --install-extension editors/vscode/zenith-1.0.0.vsix
